# KCIS APCS C++ 學生教材

在 VS Code 開啟自己的教材 repo，從當週 README 查看課程內容與題目。

Week 13～14 完成巢狀迴圈與二維陣列。Week 15～20 每堂前 40 分鐘挑戰一題 APCS 歷屆實作題，每週的三題回家練習列在當週 README，題目放在 `problems/basic/` 與 `problems/advanced/`；後 40 分鐘製作自己的個人作品集，學習 HTML／CSS，並透過 GitHub Pages 發布。

網頁課請從 [Portfolio 範本](https://github.com/kcisAPCS/portfolio) 點選 **Use this template**，在自己的帳號建立 `portfolio` repo，再依其中的 README 操作。網頁課以第 1～6 週編排，對應本課程 Week 15～20。
