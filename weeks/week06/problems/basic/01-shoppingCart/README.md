# 01 購物結帳清單

難度：基礎

## 題目說明

超市收銀系統依序掃描顧客購買的商品金額。系統持續讀取金額，直到輸入 -1 時表示掃描結束（結帳哨兵值）。

請輸出這名顧客購買的「商品總件數」與「應付總金額」。

注意：結帳標記 -1 為停止訊號，不計入商品件數也不計入總金額。若一開始第一個輸入就是 -1，表示未購買任何商品，輸出件數 0 與總金額 0。

## 輸入格式

連續輸入若干個整數，每個整數以空格或換行分隔，最後以 -1 結尾。

## 輸出格式

輸出一行兩個整數，以空格分隔，分別代表商品總件數與應付總金額。

## 資料範圍

每件商品金額為 0 到 100000 之間的整數；總件數不超過 10000 件。

## 範例 1

### 輸入

```text
35 120 40 15 -1
```

### 輸出

```text
4 210
```

## 範例 2

### 輸入

```text
-1
```

### 輸出

```text
0 0
```

## 範例說明

- 範例 1：共購買 4 件商品（35, 120, 40, 15），總金額為 35 + 120 + 40 + 15 = 210。結尾的 -1 不計入件數與金額。
- 範例 2：首個輸入即為 -1，件數為 0，金額為 0。
