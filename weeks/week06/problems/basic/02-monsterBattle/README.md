# 02 守護怪獸對戰

難度：基礎

## 題目說明

冒險者在迷宮中遭遇一隻守護怪獸，怪獸的初始生命值（HP）為 H。冒險者發動連續攻擊，每回合輸入一個正整數 D，表示該回合對怪獸造成的傷害值。

怪獸每受到一次傷害，生命值就減少相應數值。戰鬥持續進行，直到怪獸的生命值小於或等於 0（怪獸被擊敗）為止。

請計算冒險者總共進行了多少回合的攻擊才擊敗怪獸。

## 輸入格式

第一行輸入一個正整數 H，代表怪獸初始生命值。
接下來若干個正整數 D（以空格或換行分隔），代表每回合造成的傷害。當怪獸生命值小於或等於 0 時戰鬥立刻結束，不再讀取後續傷害。

## 輸出格式

輸出一個整數，代表擊敗怪獸所需的回合數。

## 資料範圍

1 ≤ H ≤ 1000000000；每回合傷害 1 ≤ D ≤ 1000000000；保證提供的傷害總和足以擊敗怪獸。

## 範例 1

### 輸入

```text
100
30
40
35
```

### 輸出

```text
3
```

## 範例 2

### 輸入

```text
50
50
```

### 輸出

```text
1
```

## 範例說明

- 範例 1：初始 HP 100。第 1 回合扣 30 剩 70；第 2 回合扣 40 剩 30；第 3 回合扣 35 剩 -5（小於等於 0），怪獸倒下，共 3 回合。
- 範例 2：第 1 回合造成 50 傷害，怪獸 HP 歸 0，共 1 回合。
