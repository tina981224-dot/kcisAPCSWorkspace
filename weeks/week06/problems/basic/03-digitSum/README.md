# 03 密碼數位拆解

難度：基礎

## 題目說明

在密碼學與數值分析中，經常需要對一個整數的各個數位進行拆解處理。

給定一個非負整數 n，請撰寫程式計算並輸出該整數的「總位數（長度）」以及「所有數位的總和」。

注意：若輸入為 0，其位數長度為 1，數位總和為 0。

## 輸入格式

輸入一個非負整數 n。

## 輸出格式

輸出一行兩個整數，以空格分隔，分別代表總位數與各位數字之和。

## 資料範圍

0 ≤ n ≤ 2000000000。

## 範例 1

### 輸入

```text
2026
```

### 輸出

```text
4 10
```

## 範例 2

### 輸入

```text
0
```

### 輸出

```text
1 0
```

## 範例 3

### 輸入

```text
9
```

### 輸出

```text
1 9
```

## 範例說明

- 範例 1：整數 2026 共有 4 個位數，各數位總和為 2 + 0 + 2 + 6 = 10。
- 範例 2：整數 0 共有 1 個位數，數位和為 0。
- 範例 3：整數 9 共有 1 個位數，數位和為 9。
