# 05 共用教室座位

難度：進階

## 題目說明

數個班級輪流使用同一間教室，使用時段不重疊。請為每間教室找出能容納所有班級的最少座位數。

## 輸入格式

依序輸入各教室的班級人數，每間教室以 0 結束。若新的一組第一個數字就是 0，表示全部輸入結束。空格與換行都可分隔數字。

## 輸出格式

每間教室輸出一行最少座位數；結束標記不產生輸出。

## 資料範圍

最多 100 間教室，每間 1～100 個班級；每班 1～1000 人。

## 範例

### 輸入

```text
22 33 44 55 0
5 6 7 5 7 0
0
```

### 輸出

```text
55
7
```

## 範例說明

同一時間只需容納其中一班，因此取各組最大人數。
