# 02 場次座位分配

難度：進階

## 題目說明

活動有多個場次。每個場次依序收到數筆團體入場申請。只有剩餘座位足夠容納整個團體時，才接受申請並扣除座位；否則拒絕，剩餘座位不變。請分別統計每場接受與拒絕的團體數，以及最後剩餘的座位數。

## 輸入格式

每個場次先輸入兩個整數 capacity、requests，表示起始座位數與申請筆數。接著輸入 requests 個整數，依序表示各團體的人數。

重複處理場次，直到讀到 `0 0` 為止。`0 0` 是結束標記，不屬於任何場次，也不輸出結果。

## 輸出格式

每個場次輸出一行三個整數：接受團體數、拒絕團體數、剩餘座位數，以空格分隔。

## 資料範圍

每個場次滿足 1 ≤ capacity ≤ 100000、1 ≤ requests ≤ 100；每個團體有 1～100000 人。最多 20 個場次。

## 範例

### 輸入

```text
10 4
4 8 3 3
5 3
6 2 3
0 0
```

### 輸出

```text
3 1 0
2 1 0
```

## 範例說明

第一場先接受 4 人，剩下 6 個座位；8 人的團體無法完整入場，後面的兩個 3 人團體都可接受。第二場拒絕 6 人團體後，依序接受 2 人與 3 人團體。
