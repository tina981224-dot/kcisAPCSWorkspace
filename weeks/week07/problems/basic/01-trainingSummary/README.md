# 01 訓練計時摘要

難度：基礎

## 題目說明

訓練場記錄每圈耗時，希望統計達到目標時間的圈數，以及全部圈數的總耗時。耗時小於或等於目標時間，就算達標。請將總耗時換算成「完整分鐘數」與「不足一分鐘的秒數」。

## 輸入格式

第一行有兩個整數 n、limit，分別表示圈數與目標秒數。

接著有 n 個整數，依序表示每圈的耗時（秒）。整數可以分布在多行；讀滿 n 筆即結束。

## 輸出格式

輸出一行三個整數，依序為達標圈數、總耗時的完整分鐘數、剩餘秒數，以空格分隔。

## 資料範圍

1 ≤ n ≤ 100；1 ≤ limit ≤ 3600；每圈耗時介於 1～3600 秒。

## 範例

### 輸入

```text
4 65
60 70 55 75
```

### 輸出

```text
2 4 20
```

## 範例說明

60 秒與 55 秒達標，共 2 圈。總耗時為 260 秒，也就是 4 分 20 秒。
