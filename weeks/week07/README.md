# Week 07：條件與迴圈綜合練習

## 今天的內容

這週用兩題綜合練習，把前面學過的輸入輸出、整除與餘數、條件判斷、`for`、`while` 再寫一次。先想清楚要讀入什麼、每輪要更新哪些變數，再動手寫程式。

## 題目

本週只有以下兩題。基礎題練習逐筆處理、條件與時間換算；進階題練習多場次、停止標記與狀態更新。先完成基礎題，再視時間挑戰進階題；沒有做完的部分不列為課後作業。作答檔 `main.cpp` 留空，請自行撰寫完整程式。

| 題目 | 難度 |
|---|---|
| [01 訓練計時摘要](problems/basic/01-trainingSummary/README.md) | 基礎 |
| [02 場次座位分配](problems/advanced/02-seatAllocation/README.md) | 進階 |

## 操作與測試

在 VS Code 開啟題目資料夾，閱讀 README 後從頭完成程式。空白 `main.cpp` 尚不能編譯，要先寫出程式入口。修改後重新編譯，用範例核對結果，再試零、最小值或邊界情況；不要額外輸出「請輸入」等提示文字。

範例中的空格與空行都是輸入輸出的一部分。題目寫「直到輸入結束」時，Windows 終端機可在新行按 Ctrl+Z 再按 Enter；WSL／Linux 可在空行按 Ctrl+D。這些按鍵不屬於輸入資料。

下課前確認程式已儲存；要保留的進度請 commit 並 push 到自己的 GitHub repo。
