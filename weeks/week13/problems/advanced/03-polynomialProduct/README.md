# 03 多項式模型相乘

難度：進階

## 題目說明

兩個模型分別用多項式表示，合成模型是兩式的乘積。係數相乘時，次方相加；同次方的結果再相加。這是數學延伸選做題。

## 輸入格式

每組兩行：各行先輸入非負整數次數 d，接著 d + 1 個係數，從最高次到常數項。讀到輸入結束。

## 輸出格式

每組輸出乘積的所有係數，由兩式次數和到 0 次；即使係數為 0 也保留，以一個空格分隔。

## 資料範圍

兩式次數皆為 0～10；係數 −100～100；最多 100 組，最高次係數可為 0。

## 範例

### 輸入

```text
1 1 2
1 1 2
```

### 輸出

```text
1 4 4
```

## 範例說明

(x + 2)(x + 2) = x² + 4x + 4。
