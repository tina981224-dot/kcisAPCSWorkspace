# 02 空心圖形輸出

難度：進階

## 題目說明

顯示器測試程式提供空心正方形與菱形。輸入種類及尺寸，輸出輪廓，內部填半形空格。

## 輸入格式

一行兩個整數 kind、s。kind = 1 表示邊長 s 的正方形；kind = 2 表示高度與最寬列均為 2s − 1 的菱形。

## 輸出格式

輸出一個圖案。正方形邊界為 *；菱形第 r 列的兩個邊界位於中心左右各 s − 1 − |r − s| 的位置（r 從 1 開始）。不要輸出行尾空格。

## 資料範圍

kind 為 1 或 2；1 ≤ s ≤ 30。

## 範例 1

### 輸入

```text
2 3
```

### 輸出

```text
  *
 * *
*   *
 * *
  *
```

## 範例 2

### 輸入

```text
1 1
```

### 輸出

```text
*
```

## 範例說明

尺寸 3 的菱形共有 5 列；尺寸 1 的任一圖形都是一個星號。
