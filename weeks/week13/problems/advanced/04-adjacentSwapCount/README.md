# 04 相鄰交換排序

難度：進階

## 題目說明

排列工具只允許交換相鄰兩個數字。採用以下流程：每回合由左到右查看每一對相鄰數字，左邊較大就交換；重複直到整回合沒有交換。統計交換次數並輸出排列結果。本題為排序流程選做。

## 輸入格式

第一行 n，第二行 n 個整數。

## 輸出格式

第一行交換次數；第二行由小到大排列的數字，以一個空格分隔。相同數字不交換。

## 資料範圍

1 ≤ n ≤ 3000；每個數字 0～1000000。

## 範例

### 輸入

```text
3
3 1 2
```

### 輸出

```text
2
1 2 3
```

## 範例說明

第一回合交換 3 與 1，再交換 3 與 2，共兩次。
