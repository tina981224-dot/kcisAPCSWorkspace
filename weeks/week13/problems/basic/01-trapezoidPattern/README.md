# 01 梯形測試圖

難度：基礎

## 題目說明

終端機顯示測試需要一組梯形圖案。從第一行 a 個星號開始，每行增減一個，直到最後一行有 b 個星號。

## 輸入格式

每筆兩個正整數 a、b，直到輸入結束。

## 輸出格式

每筆輸出一個左對齊圖案。兩個圖案之間輸出一行 ----------；最後不加分隔線。a = b 時只輸出一行。

## 資料範圍

1 ≤ a、b ≤ 50；最多 20 筆。

## 範例

### 輸入

```text
2 4
3 3
```

### 輸出

```text
**
***
****
----------
***
```

## 範例說明

第一筆逐行增加到 4；第二筆上下底相等，只印一行。
