# Week 13：巢狀迴圈與圖案輸出

## 今天的內容

巢狀迴圈的外層與內層各自代表什麼？先畫小尺寸圖案或配對表，再決定範圍。輸出圖案時，行首空格會影響位置。排序與多項式題可依興趣選做。

## 80 分鐘安排

本週與下週連續完成兩項 C++ 語法。前 15 分鐘畫出兩層迴圈如何走訪行與列；接著 20 分鐘一起寫小尺寸圖案；30 分鐘練習 01；最後 15 分鐘核對空格、換行與邊界。網頁課從 Week 15 開始。

課後可選做 02；03、04 保留作延伸，不列為本週必做。

## 操作與測試

在 VS Code 開啟題目資料夾，閱讀 README 後完成程式。空白 main.cpp 尚不能編譯，要先寫出程式入口。修改後重新編譯，用範例核對結果，再試零、最小值或邊界情況；不要額外輸出「請輸入」等提示文字。

範例中的空格與空行都是輸入輸出的一部分。題目寫「直到輸入結束」時，Windows 終端機可在新行按 Ctrl+Z 再按 Enter；WSL／Linux 可在空行按 Ctrl+D。這些按鍵不屬於輸入資料。
