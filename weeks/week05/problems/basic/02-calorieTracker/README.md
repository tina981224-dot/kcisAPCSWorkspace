# 02 每日熱量追蹤

難度：基礎

## 題目說明

小明正在進行自主體能訓練，連續記錄了 n 天的運動消耗熱量（大卡）。請撰寫一個程式，計算這 n 天的「總消耗熱量」以及「平均每日消耗熱量」。

注意：平均每日消耗熱量請以整數除法計算，直接捨去小數點後的數值。

## 輸入格式

第一行輸入一個正整數 n，表示記錄的天數。
第二行輸入 n 個正整數，以空格分隔，依序代表每天消耗的熱量（大卡）。

## 輸出格式

輸出一行兩個整數，以一個空格分隔，分別代表總消耗熱量與平均每日消耗熱量。

## 資料範圍

1 ≤ n ≤ 1000；每天消耗熱量為 1 到 10000 之間的整數。

## 範例 1

### 輸入

```text
5
300 450 250 400 350
```

### 輸出

```text
1750 350
```

## 範例 2

### 輸入

```text
3
500 620 400
```

### 輸出

```text
1520 506
```

## 範例說明

- 範例 1：5 天總和為 300 + 450 + 250 + 400 + 350 = 1750，平均為 1750 / 5 = 350。
- 範例 2：3 天總和為 500 + 620 + 400 = 1520，整數平均為 1520 / 3 = 506（捨去小數點）。
