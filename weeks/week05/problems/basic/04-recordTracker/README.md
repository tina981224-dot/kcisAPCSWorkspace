# 04 最高與最低分

難度：基礎

## 題目說明

某項體能測驗有 n 名選手參加。教練需要快速找出所有成績中的「最高分」與「最低分」，以便了解整體選手的表現差距。

請撰寫程式讀取 n 位選手的成績，並輸出最高分與最低分。

## 輸入格式

第一行輸入一個正整數 n，表示選手人數。
第二行輸入 n 個整數，以空格分隔，代表每位選手的成績。

## 輸出格式

輸出一行兩個整數，以空格分隔，分別為最高分與最低分。

## 資料範圍

1 ≤ n ≤ 1000；成績為 0 到 10000 之間的整數。

## 範例 1

### 輸入

```text
5
88 95 72 100 64
```

### 輸出

```text
100 64
```

## 範例 2

### 輸入

```text
1
85
```

### 輸出

```text
85 85
```

## 範例說明

- 範例 1：5 個成績中，最高分為 100，最低分為 64。
- 範例 2：只有 1 位選手，最高分與最低分皆為 85。
