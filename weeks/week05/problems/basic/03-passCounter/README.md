# 03 檢定及格計數

難度：基礎

## 題目說明

學校舉辦程式能力檢定，共有 n 位學生參加，檢定的及格分數為 k 分。現在依序給出這 n 位學生的成績，請寫一個程式計算「及格人數（成績 ≥ k）」與「未及格人數（成績 < k）」。

## 輸入格式

第一行包含兩個整數 n 和 k，以空格分隔，分別代表參加人數與及格分數門檻。
第二行包含 n 個整數，以空格分隔，依序代表每位學生的成績。

## 輸出格式

輸出一行兩個整數，以空格分隔，分別為及格人數與未及格人數。

## 資料範圍

1 ≤ n ≤ 1000；0 ≤ k ≤ 100；學生成績為 0 到 100 之間的整數。

## 範例 1

### 輸入

```text
6 60
75 58 60 90 45 82
```

### 輸出

```text
4 2
```

## 範例 2

### 輸入

```text
4 80
50 60 70 79
```

### 輸出

```text
0 4
```

## 範例說明

- 範例 1：及格門檻為 60 分。成績為 75、60、90、82 的同學及格（共 4 人）；成績為 58、45 的同學未及格（共 2 人）。
- 範例 2：門檻為 80 分，所有學生成績均未達 80 分，及格 0 人，未及格 4 人。
