# 05 階梯集點回饋

難度：進階

## 題目說明

某便利商店推出了集點回饋活動。會員在活動期間共進行了 n 筆消費。

回饋點數的計算規則如下：
1. 每筆消費金額每滿 100 元，可獲得 1 點基本點數（未滿 100 元的部分不計點數，例如 280 元得 2 點，95 元得 0 點）。
2. 若單筆消費金額達到或超過 500 元，屬於大額消費，該筆消費額外加贈 5 點獎勵點數（例如 520 元得 5 點基本點數 + 5 點獎勵點數 = 10 點）。

請計算這位會員在這 n 筆消費中，累積的「總消費金額」與「總獲得點數」。

## 輸入格式

第一行包含一個正整數 n，表示消費筆數。
第二行包含 n 個整數，以空格分隔（或分行輸入），代表各筆消費金額。

## 輸出格式

輸出一行兩個整數，以空格分隔，分別代表總消費金額與總獲得點數。

## 資料範圍

1 ≤ n ≤ 10000；每筆消費金額為 0 到 100000 之間的整數。

## 範例 1

### 輸入

```text
3
250 600 80
```

### 輸出

```text
930 13
```

## 範例 2

### 輸入

```text
4
100 500 499 0
```

### 輸出

```text
1099 15
```

## 範例說明

- 範例 1：
  - 第 1 筆 250 元：基本點數 250 / 100 = 2 點。
  - 第 2 筆 600 元：基本點數 600 / 100 = 6 點，滿 500 元加贈 5 點，共 11 點。
  - 第 3 筆 80 元：未滿 100 元，0 點。
  - 總金額 250 + 600 + 80 = 930 元；總點數 2 + 11 + 0 = 13 點。
- 範例 2：
  - 100 元得 1 點；500 元得 5 + 5 = 10 點；499 元得 4 點；0 元得 0 點。
  - 總金額 1099 元，總點數 15 點。
