# 08 文字母音過濾

難度：進階

## 題目說明

搜尋索引要產生簡化文字：移除英文母音 a、e、i、o、u，大小寫皆移除，其餘字元保持原順序。以 isVowel 判斷單一字元，以 removeVowels 處理一行文字。

## 輸入格式

逐行讀入文字，直到輸入結束。

## 輸出格式

每行輸出過濾後的結果；全部被移除時仍輸出空行。

## 資料範圍

最多 100 行，每行長度 0～1000，只含 ASCII 可列印字元。

## 範例

### 輸入

```text
There
AEIOU
City 2026!
```

### 輸出

```text
Thr

Cty 2026!
```

## 範例說明

There 移除兩個 e 後為 Thr；y 不視為母音。
