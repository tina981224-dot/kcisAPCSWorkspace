# 01 對稱代碼檢查

難度：基礎

## 題目說明

資料代碼若由左至右與由右至左讀取相同，稱為迴文。請判斷每個代碼，並將判斷工作放在名為 isPalindrome 的函式中。大小寫視為不同。

## 輸入格式

每次輸入一個不含空白的字串，直到輸入結束。

## 輸出格式

是迴文輸出 TRUE，否則輸出 FALSE。

## 資料範圍

每個字串長度 1～1000，只含英文字母與數字；最多 100 筆。

## 範例

### 輸入

```text
madam
Abba
22
```

### 輸出

```text
TRUE
FALSE
TRUE
```

## 範例說明

madam 與 22 反向相同；Abba 的首尾大小寫不同。
