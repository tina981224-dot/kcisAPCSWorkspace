# 03 價格變動率

難度：基礎

## 題目說明

採購報表比較目前價格與前期價格。變動率定義為 (目前價格 − 前期價格) / 前期價格。請把輸入、計算及輸出分別交由函式處理。

## 輸入格式

第一行 t；接著每行兩個整數 current、previous。

## 輸出格式

每筆輸出變動率，四捨五入到小數點後兩位，不乘以 100，也不加百分號。

## 資料範圍

1 ≤ t ≤ 100；1 ≤ current、previous ≤ 1000000。

## 範例

### 輸入

```text
2
500 200
200 500
```

### 輸出

```text
1.50
-0.60
```

## 範例說明

第一筆增加 300，除以前期的 200 得到 1.5。
