# 04 鐘面指針夾角

難度：基礎

## 題目說明

以連續移動的類比時鐘為例，時針每小時走 30 度、分針每分鐘走 6 度。已知二十四小時制的時與分，計算兩針之間較小的夾角。請用 Degree 函式計算。

## 輸入格式

每筆兩個整數 h、m，直到輸入結束。

## 輸出格式

每筆輸出角度，固定一位小數，範圍為 0～180 度。

## 資料範圍

0 ≤ h ≤ 23；0 ≤ m ≤ 59；最多 100 筆。

## 範例

### 輸入

```text
0 0
4 30
23 0
```

### 輸出

```text
0.0
45.0
30.0
```

## 範例說明

4:30 的時針位於 135 度，分針位於 180 度，相差 45 度。
