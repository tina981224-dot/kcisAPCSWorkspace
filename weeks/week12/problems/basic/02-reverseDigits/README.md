# 02 編號數字反轉

難度：基礎

## 題目說明

資料轉換工具要把整數的十進位數字倒過來，負號保留在最前面，反轉後的前導零不保留。請寫 reverseDigit 函式並由主程式讀入、輸出。

## 輸入格式

每行一個整數 n，直到輸入結束。

## 輸出格式

每筆輸出反轉後的整數。

## 資料範圍

−1000000000 ≤ n ≤ 1000000000；最多 100 筆。

## 範例

### 輸入

```text
12345
5600
-532
0
```

### 輸出

```text
54321
65
-235
0
```

## 範例說明

5600 倒過來是 0065，整數輸出為 65；負數保留符號。
